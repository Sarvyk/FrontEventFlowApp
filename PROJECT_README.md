# EventFlow - Frontend Application Documentation

## Описание проекта

EventFlow - это веб-приложение для организации и участия в мероприятиях. Приложение позволяет пользователям:
- Регистрироваться и авторизовываться
- Искать и просматривать мероприятия
- Зарегистрироваться на мероприятия
- Организовывать собственные мероприятия
- Управлять своим профилем

- Обновляет статус заявки через сервис `organizerService.updateApplicationStatus()`

## Маршрутизация

В приложении реализована следующая маршрутизация:
- `/` — Главная страница (HomePage)
- `/events` — Список мероприятий (EventListPage, публичный маршрут)
- `/login` — Страница входа (LoginWrapper)
- `/register` — Страница регистрации (RegisterWrapper)
- `/profile` — Профиль пользователя (ProtectedRoute → Profile)
- `/organizer-application` — Заявка на организатора (ProtectedRoute → OrganizerApplication)
- `/admin` — Админ-панель управления заявками на организатора (ProtectedRoute adminOnly → AdminPanel, только для роли Admin)

### authService.ts
- Файл: `src/services/authService.ts`

  - register: Регистрация нового пользователя
  - login: Авторизация по Email и паролю
  - refreshToken: Обновление токена авторизации
  - confirmEmail: Подтверждение email
  - saveAuthTokens: Сохранение токенов в localStorage с временем истечения
  - getAuthTokens: Получение токенов из localStorage
  - clearAuthTokens: Удаление токенов
  - isTokenExpired: Проверка срока действия токена

## Защита от прямого доступа к страницам авторизации
- При попытке перехода на страницу `/login` или `/register` с действительным токеном, пользователь автоматически перенаправляется на главную страницу
- Страницы авторизации отображаются только для неавторизованных пользователей

## Реализованные функции авторизации

### Сохранение токенов с временем истечения
- Все токены (access и refresh) сохраняются в localStorage
- Время истечения токена также сохраняется для последующей проверки
- При каждом запросе автоматически добавляется заголовок `Authorization: Bearer [токен]`

### Механизм обновления токенов
- При получении ошибки 401 (Unauthorized) автоматически пытается обновить access токен через refresh endpoint
- Если обновление успешно, повторяет оригинальный запрос с новым токеном
- При неудачном обновлении происходит редирект на страницу входа

### Проверка срока действия токенов
- Добавлен метод для проверки истечения срока действия токена
- Система корректно обрабатывает даты в строковом формате (ISO 8601)

## API Endpoints

### Auth endpoints:
- POST `/Auth/RegisterUser` - Регистрация пользователя
- POST `/Auth/UserLogin` - Авторизация пользователя (возвращает accessToken, refreshToken и expiresAt)
- POST `/Auth/refresh` - Обновление токена
- GET `/Auth/confirm-email` - Подтверждение email

### Event endpoints:
- POST `/Event` - Создание мероприятия (требует роль Organizer или Admin)
- GET `/Event/{id}` - Получение данных о мероприятии
- PUT `/Event/{id}` - Обновление данных мероприятия

### Organizer endpoints:
- POST `/Organizer` - Подать заявку на организатора
- GET `/Organizer/my` - Получить свою заявку на организатора
- GET `/admin/Organizer?offset=&count=` - Получить все заявки (только для Admin)
  Возвращает `{ items: OrganizerDto[], totalCount: number }` где `OrganizerDto` содержит поля: id, userId, companyName, description, webSite, isVerified, isDelete, reason, eventsCount, user (firstName, lastName, email, phoneNumber)
- PUT `/admin/Organizer/{id}` - Обновить статус заявки (только для Admin). Тело запроса: `{ isVerified: boolean, reason?: string }`

### Registration endpoints:
- POST `/Registration/{eventId}` - Регистрация на мероприятие
- DELETE `/Registration/{eventId}` - Отмена регистрации
- GET `/Registration/my` - Получить список своих регистраций
- GET `/Registration/{eventId}/all` - Получить список зарегистрировавшихся

### Ticket endpoints:
- GET `/Ticket/{id}` - Получить билет по ID
- GET `/users/me/tickets` - Получить список билетов пользователя
- GET `/Ticket/{eventId}/all` - Получить список билетов по ID мероприятия

### User endpoints:
- PUT `/User/UpdateUserProfile` - Обновление профиля пользователя
- GET `/User/GetProfile` - Получение данных профиля пользователя
